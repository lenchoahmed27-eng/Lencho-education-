# Lencho Education

Bilingual learning platform for Ethiopian students in Grades 9-12, with entrance-exam practice in Afaan Oromo and English.

## Features
- Study notes and sample multiple-choice questions
- Answers and explanations
- Practice scoring
- Mobile-friendly layout

## Publish with GitHub Pages
1. Upload the contents of this ZIP to the repository root (the files should appear directly in the repository, not inside another folder).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Project status
This is a starter prototype. It does not yet contain a complete Grade 9-12 curriculum or a complete set of official past examination papers.
